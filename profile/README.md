# Cinebh

Cinebh is an internship project for building CinemaApp, a cinema
ticketing and management application.

## Repositories

| Repository | Purpose | Technologies |
| --- | --- | --- |
| [Frontend](https://github.com/Cinebh/cinebh-frontend) | Web application and full-stack startup | React, TypeScript, Vite |
| [Backend](https://github.com/Cinebh/cinebh-backend) | REST API and database | Java, Spring Boot, PostgreSQL |

## Setup and Deployment

Follow the [Setup and Deployment Guide](https://github.com/Cinebh/cinebh-frontend#readme)
to configure and run the complete application.
